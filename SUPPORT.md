# Support

## Documentation

Start with the [README](README.md) for installation, CLI usage, MCP integration, configuration, and
limitations. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for implementation details.

## Questions and bug reports

- Search [existing issues](https://github.com/yanulabs/tsray/issues) before opening a new one.
- Use the bug report or feature request template and include a minimal reproduction when relevant.
- Include the tsray version, Node.js version, operating system, and MCP client for runtime issues.
- Community support is best-effort and has no service-level agreement.

## Contributions and conduct

See [CONTRIBUTING.md](CONTRIBUTING.md) for development setup and review expectations, and
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for community standards.

## Security

Do not post vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md) to report them privately.
